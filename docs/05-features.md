# 05. 기능 요구사항 및 유저 스토리

우선순위: **P0** = MVP 필수, **P1** = MVP 직후, **P2** = 앱 단계 또는 이후.

## F1. 자산·이력 입력

| ID | 스토리 | 우선순위 |
|---|---|---|
| F1-1 | 부동산을 등록하고 계약일·잔금일·취득가액을 입력한다. 잔금일 입력 시 취득일이 자동 판정된다 | P0 |
| F1-2 | 전입/전출을 기록해 거주기간이 자동 계산된다 | P0 |
| F1-3 | 임대차 계약(보증금·월세·기간·갱신 여부)을 기록한다 | P0 |
| F1-4 | 증권 계좌를 유형(일반/ISA/연금저축/IRP)과 함께 등록한다. ISA는 가입일·만기일·유형(일반/서민)을 입력한다 | P0 |
| F1-5 | 티커별 매수/매도 이력(체결일, 수량, 단가, 환율)을 입력한다 | P0 |
| F1-6 | 매수 이력을 CSV로 일괄 가져온다 (증권사 거래내역 포맷 매핑) | P1 |
| F1-7 | 세대 구성원과 그 보유 자산을 등록한다 (1세대 판정) | P0 |
| F1-8 | 배당 수령 이력을 입력한다 | P1 |
| F1-9 | 연도별 공시가격을 입력한다 (보유세 계산 입력) | P1 |
| F1-10 | 잘못 입력한 이벤트를 수정·취소한다 (소프트 삭제, 이력 보존) | P0 |

**입력 UX 원칙**: 이벤트 원장을 직접 보여주지 않는다. "아파트 샀어요" 위저드가 계약일→중도금→잔금 순으로 물어보고 내부적으로 이벤트를 생성한다. 파워유저용 타임라인 원장 뷰는 별도 제공.

## F2. 세액 계산·현황 대시보드

| ID | 스토리 | 우선순위 |
|---|---|---|
| F2-1 | 자산별 "지금 팔면" 예상 양도세를 본다 (예상 양도가 입력) | P0 |
| F2-2 | 1세대 1주택 비과세 요건 충족 여부와 근거(보유/거주기간, 주택 수 판정 트리)를 본다 | P0 |
| F2-3 | 올해 재산세·종부세 예상액을 본다 | P1 |
| F2-4 | 해외주식 연간 실현손익과 250만 공제 잔여 한도를 본다 | P0 |
| F2-5 | "올해 얼마까지 더 익절해도 비과세인가"를 본다 | P0 |
| F2-6 | ISA 만기까지 남은 기간, 비과세 한도 소진 현황을 본다 | P1 |
| F2-7 | 금융소득(배당+이자) 연간 누계와 2천만 원 도달 경고를 본다 | P1 |
| F2-8 | 모든 계산 결과에서 "왜?"를 눌러 적용 규칙·조문·판정 과정을 본다 (explanation trace) | P0 |
| F2-9 | 대주주 판정 경고 (연말 기준 종목별 보유금액) | P2 |
| F2-10 | 임대소득세 예상 (분리 vs 종합 비교) | P2 |

## F4. 시나리오 시뮬레이션

| ID | 스토리 | 우선순위 |
|---|---|---|
| F4-1 | "이 자산을 날짜 D에 가격 P로 판다"는 가상 이벤트로 세액을 시뮬레이션한다 | P0 |
| F4-2 | 두 시나리오(매도 시점/순서 차이)를 나란히 비교한다 | P0 |
| F4-3 | "N개월 더 보유하면 세액이 어떻게 변하나" 시간축 스윕 차트를 본다 (비과세 요건 충족 시점, 장특공제 증가 구간이 보임) | P1 |
| F4-4 | 다주택 매도 순서 조합별 총 세액 비교 (A→B vs B→A) | P1 |
| F4-5 | ISA 만기 처리 옵션(연장/해지 후 재가입/연금 이전) 비교 | P1 |
| F4-6 | 손실 종목 매도로 손익통산하는 시나리오 제안 | P2 |
| F4-7 | 증여 시나리오 (배우자 증여 후 양도 등) | P2 |

## 비기능 요구사항

| 항목 | 요구 |
|---|---|
| 정확성 | 규칙별 테스트 케이스 100% 통과. 국세청 공식 계산 사례와 대조한 회귀 스위트 |
| 투명성 | 모든 세액에 explanation trace. "규칙 미수록" 상황은 계산 불가로 명시 (그럴듯한 오답 금지) |
| 프라이버시 | 자산 데이터의 네트워크 전송 0건. 분석 수집 시에도 금액·자산 정보 제외 |
| 성능 | 이벤트 1,000건 × 시나리오 계산 < 500ms (클라이언트) |
| 오프라인 | 최초 로드 후 오프라인 계산 가능 (규칙 캐시) |
| 접근성 | 금액·판정 결과의 스크린리더 호환, 색상 외 정보 전달 수단 병행 |
| 면책 | 모든 계산 화면에 "참고용, 세무 자문 아님" 고지 |

## 화면 구성 (초안)

1. **홈 대시보드**: 자산 요약, 임박한 D-day, 최근 개정 영향 배지, 올해 실현손익/공제 잔여.
2. **자산 상세**: 타임라인(이벤트 카드), "지금 팔면" 계산, 요건 충족 진행바(보유 2년 중 1.5년 등).
3. **시나리오 빌더**: 가상 이벤트 추가 → 비교 테이블/차트.
4. **개정 리포트**: RuleSet diff → 내 세액 변화.
5. **입력 위저드**: 자산 유형별 단계형 입력.
6. **설정/데이터**: 백업, 가져오기, 세대 관리, 면책 고지.
