# taxNavi — 개인 자산 세금 내비게이터

한국 세법은 매년(때로는 연중에도) 개정되며, 부동산·주식 세제는 "핀셋 규제"로 인해 취득 시점, 지역, 보유 수, 계약 시점에 따라 적용 규칙이 달라진다. 일반인이 자신의 상황에 어떤 규칙이 적용되는지 추적하는 것은 사실상 불가능하다.

**taxNavi**는 사용자가 보유한 부동산과 주식의 이력(취득 계약, 잔금일, 임대차 계약, 매수 내역, 계좌 유형 등)을 **시계열 이벤트**로 입력해두면, 시행일 기반으로 버전 관리되는 **세법 규칙 데이터**와 대조하여:

1. 현재 및 미래 시점의 예상 세액을 계산하고
2. 세법 개정 시 내 세금이 어떻게 변하는지 diff로 보여주고
3. 매도 시점·순서 조정 등 절세 시나리오를 시뮬레이션한다.

## 배포 전략

- **1차: GitHub Pages** — 서버 없는 정적 SPA. 모든 자산 데이터는 브라우저(IndexedDB)에만 저장되어 개인정보가 외부로 나가지 않는다.
- **2차: 모바일 앱** — 동일한 TypeScript 코어(도메인 모델 + 규칙 엔진)를 재사용하여 앱으로 확장.

## 핵심 설계 원칙

1. **이벤트는 불변, 판정은 파생** — 사용자는 사실(계약했다, 잔금 쳤다, 매수했다)만 기록한다. "1세대 1주택인가", "중과 대상인가" 같은 판정은 이벤트와 규칙으로부터 계산되는 파생값이다.
2. **세법 규칙은 코드가 아니라 데이터** — 세율, 공제, 요건은 시행일·적용조건이 붙은 JSON 규칙 파일로 저장소에서 버전 관리한다. 세법이 바뀌면 코드 배포 없이 규칙 파일만 갱신한다.
3. **모든 규칙은 정부 원문에 뿌리를 둔다** — 법령·시행령·고시·보도자료 원본을 자동 수집해 해시와 함께 불변 보관하고, 규칙은 보관된 원문의 특정 조문을 참조한다. 원문 없는 규칙은 배포하지 않는다.
4. **모든 계산은 근거를 남긴다** — 산출 세액에는 어떤 규칙(조문·시행일)이 어떤 순서로 적용되었는지 추적 가능한 설명이 붙는다.
5. **개인 자산 데이터는 로컬에만** — 1차 버전은 서버가 없다. 백업/이관은 암호화된 파일 내보내기로 해결한다.

> ⚠️ 이 앱의 계산 결과는 참고용이며 세무 자문을 대체하지 않는다. 이 면책 원칙은 UI 전반에 명시한다.

2026년 세제개편안(2026-08-03 발표) 분석에서 확인된 것:

- 개편안은 **장기보유특별공제를 장기거주소득공제로 대체**한다. 2028년 거주 연6%·보유 연2%, 2029년부터 보유공제 완전 폐지. 실거주가 짧은 주택은 **2029년보다 2028년 양도가 유리**해지는 역전이 발생한다.
- **상생임대 특례에 양도기한이 신설**된다. 종전에는 시점 제한이 없었으나 계약 종료 후 1년(최대 2029-12-31) 내 양도분에만 거주요건 면제가 적용된다.
- 해외 근무 출국의 비거주기간 3년 거주인정(개편안 §18)은 **공제율 산정에만** 적용되며 비과세 2년 거주요건에는 적용되지 않는다.
- 비거주자 판정은 1세대 1주택 비과세를 전면 배제하므로, 이 판정 하나가 세액을 수 배로 바꾼다.
- **매도 순서와 시점만으로 총 양도세가 2억 9,383만원 ~ 8억 6,386만원까지 벌어진다** (5억 7,003만원 차이). 2주택이라 한 채는 반드시 과세되므로, 양도차익이 작은 쪽(시범한양)을 먼저 과세로 떠안고 큰 쪽(과천자이)을 1주택 비과세로 넘기는 순서가 결정적이다. 최선은 **시범한양 2027년(2억 1,893만원) → 과천자이 2028년(7,490만원·비과세)**, 최악은 그 반대 순서를 2029년에 몰아 하는 것이다.
- 중과 한시완화(개편안 12)는 **완화기간 중 양도에 장기보유특별공제를 배제**한다. 세율 인하분보다 공제 배제 손실이 커서, 2주택 상태 양도는 완화기간에도 여전히 최악의 선택지다.
- 재건축은 개편안에 별도 규정이 없어 **현행 시행령 §156의2·§166**으로 판정한다. 관리처분계획인가 → 조합원입주권 전환(인가일 이후 기간 장특공제 배제, 상생임대 경로 종료), 멸실 → 주택분 재산세가 토지분으로 바뀌고 종부세 합산 제외(보유세 급감), 준공 → 주택 복귀 + 공시가 급등(보유세 급증)의 3단 변곡점이 있다.
- **재건축 일정이 상생임대의 법정 기한보다 먼저 문을 닫는다.** 시범한양 예정 일정('27년 사업시행인가 → '29년 관리처분계획인가) 기준으로, 상생임대 거주요건 면제의 법정 양도기한은 2029-07-31이지만 2029년 관리처분계획인가로 주택이 조합원입주권으로 바뀌면 "주택의 양도"가 아니게 되어 경로가 그 전에 닫힌다. **실질 마지막 해는 2028년**이고 인가일은 통제할 수 없으므로 2029년은 계획에 넣지 않는 것이 안전하다. 반대로 멸실은 이 일정에 없어 2026~2029년 중 보유세가 토지분으로 떨어지는 구간도 없다.
- **부부공동명의(각 50%)가 결론을 전부 바꾼다.** 양도세·종부세는 모두 인별 과세라 지분 분할이 그대로 절세로 이어진다. 최선 매도안 3억 4,631만원 → **2억 9,383만원**(−5,248만원), 보유세는 연 −479만원. 반면 **고가주택 12억 판정은 주택 전체 양도가액** 기준이라 공동명의로 낮출 수 없고, **재산세는 물건별 과세**라 총액이 줄지 않는다(납부만 지분 안분).
- **개편안은 공동명의의 종부세 이점을 크게 깎았다.** 다주택 기본공제 9억이 **「4억 + (5억 × 거주주택 공시가격 ÷ 주택 공시가격 합계액)」**으로 쪼개져(종부법 §8①), **4억만 각자 무조건** 받고 **5억분은 거주주택 가액 비중만큼만** 받는다. 비거주 부부공동명의 2주택은 **부부 합 8억이 상한**이며 "각 9억 = 합 18억"이 아니다. 문답자료 p.40 원문: *"기본공제 9억원 중 4억원은 기본 적용, 5억원(4억원 초과분)은 주택가액 합계에서 거주주택 가액 비중만큼만 공제"*.
- **개편안 (2)의 「과세대상 문턱」은 기본공제와 별개로 먼저 걸린다.** 1세대1주택자는 공시가 합 **14억 초과**, 그 외는 **9억 초과**일 때만 납세의무가 성립한다(종부법 §7①). 확정 공시가(과천자이 13.07억 + 시범한양 6.00억 = **19.07억**, 2026-01-01 기준)에서 각자 귀속액은 **9.535억**으로 문턱을 근소하게 넘는다 → 과세대상이다. 부부 합 종부세는 2026년 205,440원 → 2027~2029년 각 **944,452원**(과천자이 거주) / **2,829,480원**(비거주, 농특세 20% 별도 565,896원). 단독명의였다면 2027년 이후 연 7,614,880원. 공시가가 1인 귀속 9억(=합 18억) 이하로만 내려가도 0원이 되는 **경계 구간**이라 매년 3월 공시가 발표 후 재확인이 필요하다.
- **거주 여부가 종부세를 3배로 벌린다.** 기본공제 5억분이 거주주택 가액 비중에 비례하므로, 과천자이에 거주하면 각 4억 + 5억×68.5% = 7.43억(부부 합 14.85억)을 공제받아 2027년 종부세가 944,452원이지만, 비거주면 각 4억(합 8억)뿐이라 2,829,480원이 된다(공시가 2026년 값 고정 기준).
- **재산세에는 과세표준상한제가 있고 종부세에는 없다 — 이 비대칭이 공시가 급등 시나리오의 결론을 만든다.** 지방세법 **§110③**(신설 2023.3.14)은 「과세표준상한액 = 직전연도 공시가×공정비율 + (당해 공시가×공정비율×**5%**)」로 주택 과세표준의 증가를 묶는다(공정비율 60%는 시행령 §109①2, 상한율 5%는 §109의2②). 같은 법 **§122**의 세부담상한 150%는 단서에서 *"다만, 주택의 경우에는 적용하지 아니한다"*로 주택을 제외하므로, 주택 재산세에는 §110③만 작동한다. 반면 종부세에는 과세표준상한제가 없고 세부담 상한(§10·§15, 개편안 150%→200%)만 있어 공시가 상승이 세액에 거의 그대로 전달된다.
- **연 30% 상승 가정에서 보유세는 4년간 4.2배가 된다 (578만 → 2,406만원).** 공시가 합 19.07억(2026) → 41.90억(2029). 재산세는 §110③ 상한이 2027년부터 매년 걸려 558만 → 1,126만원(2.0배)에 머물지만, 종부세는 20.5만 → 1,280만원으로 뛴다(과천자이 거주·부부공동명의). 비거주면 2029년 2,943만원. 상승률은 대시보드 상단에서 조절할 수 있고 0%면 종전 계산(652만~841만원)으로 되돌아간다. **양도세는 실제 매도가 기준이라 공시가 상승과 무관하다** — 즉 공시가가 오를수록 매도 지연의 실질 비용만 커진다. 시범한양을 2027년에 정리하면 종부세 합산 대상이 1채로 줄어 2029년 보유세가 2,406만 → 1,070만원이 된다.
- **공정시장가액비율 80% 트랙의 요건에 비거주자는 없다.** 원문(상세본 p.62 / 문답 p.41~42)은 *"3주택 이상 **또는** 조정대상지역 주택 보유자(단, 1세대1주택자 제외)"*만을 요건으로 하고 `'26)60% → ('27)70% → ('28)80%`로 정한다(종부법 §13①②, 종부령 §2의4). 문답 p.42 각주는 *"2주택자가 조정지역 주택 1채, 비조정지역 주택 1채 소유한 경우 포함"*이라 조정지역 주택 1채만 있어도 80%다. 개편안 원문 전체를 검색해도 공정비율과 비거주자를 연결하는 문구는 없다(비거주자 언급은 양도세 조특법 감면·장기임대주택 특례 문맥뿐). 거주 여부는 **기본공제 5억분 비중**에만 영향을 준다. 과천·분당은 2023-01-05 해제 상태라 현재 70% 트랙이며, 재지정 시에만 '28년부터 80%가 적용되어 2028년 1,548만 / 2029년 2,709만원이 된다 — 대시보드에서 토글로 비교할 수 있다.
- **종부세 개편은 7개 조항이 한꺼번에 맞물린다** — 과세대상 문턱(§7①), 기본공제 분해(§8①), 공정시장가액비율 70%·80% 트랙(§13), '27년 중간세율 후 '28년 주택 수 구분 폐지(§9①②), 1세대1주택 세액공제의 보유→거주 전환 + 금액한도 신설('27년 800만 → '28년 이후 600만, §9⑤⑧⑨), 세부담 상한 150%→200%(§10·§15), 그리고 산출세액의 농어촌특별세 20%. 하나만 빠뜨려도 세액이 몇 배로 틀린다.
- **정부의 계산 사례를 회귀 테스트로 쓴다.** 문답자료가 직접 제시한 종부세 사례 ①②③(p.44~45)과 양도세 사례 ①②(p.38)의 세액을 오라클로 삼아 `calc.py` 실행마다 자동 대조한다. 종부세 18개 중 **17개 일치**, 양도세는 6개 전부 일치. 남은 1건(사례③ '27년)은 **원문 자체가 내부 정합하지 않는다** — 같은 표의 "세액공제 한도 전 2,141.1만원"에 '27년 한도 800만원을 적용하면 2,251.7만원이어야 하는데 원문은 1,942.1만원으로 적혀 있다.
- **자녀 증여는 같은 자산의 양도보다 비싸다.** 2013·2014년생은 증여 시점에 모두 미성년이라 증여재산공제가 1인 **2,000만원**뿐이다. 시범한양(13억) 본인 지분 6.5억을 자녀 2명에게 주면 1억 2,169만원, 부부 지분 전부면 2억 9,576만원(실효 22.8%) — 같은 집을 2027년에 과세 양도할 때의 2억 1,893만원보다 크다. 게다가 **이월과세 10년(§97의2)은 직계존비속 증여에도 적용**되고, **미성년자는 시행령 §152의3에 따라 독립세대를 구성할 수 없어** 증여해도 1세대의 주택 수가 줄지 않는다. 성년(2032·2033년) 후 증여는 공제 확대로 1,164만원 저렴하지만 그 사이 가액 상승분과 상계된다.
- **배우자 증여는 이미 공동명의라 실익이 없다.** 명의 분산 효과가 이미 확보되어 있고, 시범한양 본인 지분 6.5억은 배우자공제 6억을 조금 넘어 증여세 485만원 + 취득세 2,275만원 = 2,760만원이 발생한다.
- **공시가격은 자동 조회가 불가능했다.** realtyprice.kr·rt.molit.go.kr은 접속이 차단되고 공공데이터 API는 공동주택 공시가격을 반환하지 않았다. 현재 값(과천자이 13.07억 / 시범한양 6.00억, 2026-01-01 기준)은 사용자가 직접 확인해 입력한 확정값이며, 자동 수집은 향후 파이프라인의 미해결 항목이다(동·호수는 개인 식별 위험이 있어 저장하지 않는다). 공시가격은 매년 1월 1일 기준으로 새로 결정되므로(부동산 가격공시에 관한 법률 §18, 3월 발표) 연 상승률은 **가정 입력값**으로 두고 매년 실측치로 갱신하는 구조를 택했다.
